| Signal | 0 | 1 | 2 |
|--------|---|---|---|
| **SERP specimen** | Plain title/description | Samples in meta only | Meta + visible hero/OG match query |
| **Above-fold utility** | Text only / below fold | Small preview | Large tap-to-copy grid or live generator |
| **Intent match** | Wrong type (e.g. kaomoji for “heart emoji”) | Partial | Exact (picture emoji vs face vs Unicode font) |
| **Trust / AdSense** | Thin list | FAQ only | FAQ + how-to + platform notes (unique) |
| **Mobile** | Overflow / tiny taps | Usable | Responsive grid + copy feedback |

**Target:** ≥8/10 weighted on P0 keywords before calling a URL “comparison-ready.”
